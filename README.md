# Yousuf Ibrahim Portfolio

A personal portfolio website built as a single-page HTML resume/portfolio, designed with a clean editorial aesthetic and a Codeforces-style contest layout.

## Overview

This project showcases:
- Personal introduction and background
- Education and experience sections
- Project highlights
- Skills and competitive programming profile
- Contact details and resume link

The site is fully contained in a single `index.html` file with embedded CSS and JavaScript.

## Project Structure

```text
.
├── index.html
├── LICENSE
├── README.md
└── .gitignore (if present in your repository)
```

## Run locally

Because this is a static HTML site, you can open it directly in a browser:

```bash
# From the project directory
open index.html
```

Or serve it locally with a simple HTTP server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customize

Edit `index.html` to update:
- Name and title
- Bio and statement
- Education and experience
- Projects and links
- Contact information
- Resume download file reference

## Deployment

This project can be deployed easily on:
- GitHub Pages
- Netlify
- Vercel
- any static hosting provider

For GitHub Pages, publish the repository root or the project folder as a static site.
